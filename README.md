# Rime Lane

Full-colour Python 3 neon curling arcade for [ElbowOS](https://x.com/ElbowOS).

Aim a glowing stone up a vertical ice sheet.
Bounce off violet bumpers.
Park coral and teal rocks in the house rings.
A / D aim. Space / W charge and launch.

## Play

```
pip install -r requirements.txt
python3 rime_lane.py --play
```

## Record a 9:16 reel

```
python3 rime_lane.py --record
```
